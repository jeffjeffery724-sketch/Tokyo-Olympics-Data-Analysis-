## 🏅 Olympics Medal Dashboard – Power BI
Overview : 
The Olympics Medal Dashboard is an interactive Power BI report that provides insights into country-wise Olympic medal performance. It enables users to analyze and compare medal counts, rankings, and overall achievements through dynamic visualizations and filters.

## Key Features :

KPI cards displaying total Gold, Silver, Bronze, and Total Medals.
Top 5 countries by Gold, Silver, and Bronze medals.
Bottom 5 countries with the lowest medal performance.
Interactive country filter (NOC) for focused analysis.
Ranking and medal distribution visualizations.
Dataset
